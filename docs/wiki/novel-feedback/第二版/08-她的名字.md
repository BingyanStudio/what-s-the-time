# 第八章 她的名字 · 点评

## 优点
- "你到死都写不对她的名字"是全书情感核爆点；榛／蓁的错字哲学（"草是长给人看的，木头是自己站着的"）把物证（描样纸）、人名（户口上的榛）与主题（他爱的是一个错字）拧成一股，是全书完成度最高的设计。
- 证据链的次序好：日记末句→描样纸五遍→笔迹小尾巴→栏杆刻字，层层收拢。
- "我问的是你。不是你觉得。"——话术谱系里第一次被当场戳穿，符合大纲。

## 问题（A 级集中营）
1. **"我姐姐没有（钥匙）"与第六章互斥**：第六章明写叶蓁"常上塔画画，管修缮的人给她行了方便；她配了一把（钥匙），给了我"。既然叶蓁自己有钥匙，第八章"你有这儿的钥匙。'店里代管的。''我姐姐没有。'"这句指控就建立在错误前提上，且读者手里握着反证。改法：要么删"我姐姐没有"，要么改成"我姐姐的钥匙，后来谁也没找着"——顺手给叶蓁之死再添一层悬疑。
2. **寻找史与第五章互斥**："我找了他六年。我去过钟表店……那时候你还没来。屋子是空的，只有一个老头。"——第五章写她初到鹤川时沈叙就在店里，且她六年前（13 岁）如何独自去鹤川探店、又为何第五章全无此事？两段必须删一段。
3. **表后盖刻字（榛／蓁）未引爆**：第一章的核心伏笔在这里本应与错字主题合流——后盖上的字"像榛又像蓁"、被人刻意磨过，正是"他写错她的名字"的实物版。本章只说"磨它的人是谁，我就不问了"，既没接住伏笔，也没交代磨字人是谁、动机何在（叶蓁死后表才作为遗物退回，沈叙物理上从未接触过它，谁磨的？）。
4. **"她的死亡时间，是晚上十点三十七分"破坏诡计设计**：大纲写明"表不区分昼夜：谁也不知道那一下是上午还是晚上"，这是 10:37 的三重结构里刻意留的不确定性。榛榛一句"晚上"把设计说破。
5. 小处："暗房的手艺，我学了三天就会了"与第五章"第一天我就差点把一锅显影液弄废"（且应聘时自称干过）矛盾。

## 修改建议
- 本章是第二版的"逻辑事故高发区"，1、2、4 三条必须修，3 条建议把表后盖并入摊牌戏（让他摸出那个字，她说"你写的是我"）。
