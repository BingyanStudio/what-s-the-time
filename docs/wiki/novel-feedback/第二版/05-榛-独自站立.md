# 第五章 榛·独自站立 · 点评

## 优点
- 全书信息效率最高的一章：姐姐之死的官方版本、全家噤声机制、日记、描样纸、霍燃、进店动机，全部现实化落地。
- 好细节密集："我坐的车是往北的"、搪瓷缸豁口朝着自己、卡簧"没弯"、"这是我最后一次。不管答案是什么。"
- 视角切换由元框架支撑（章首"你说，现在，换她说话"），合法性成立。

## 问题
1. **进店时间与第一章互斥（A 级）**：本章"到鹤川是开春……第四天上午，我进了店"，第一章却是"十月初的一天，下雾"她进店、沈叙"秋天"才到鹤川。霍燃"五月里找到我的"又支持开春说。三处时间无法同时成立。
2. **"到鹤川的第三个月，我混上过一次钟楼。那天塔里在检修，上上下下都是人"**：沈叙上塔检修（第四章，十二月）明确只有师徒二人；另一次"上上下下都是人"的检修没有出处。
3. **与第八章矛盾（A 级）**：本章"铺子里只有一个人，年轻，低着头修表"（初见沈叙在店里）vs 第八章"我去过钟表店……那时候你还没来。屋子是空的，只有一个老头"。
4. "从我妈箱子底上拿的，带了九年"表述歧义：既然是从箱子底拿的，"带了九年"是"放了九年"还是随身九年？改为"跟了她九年"或"压了九年"。

## 修改建议
- 以第一章（十月初）为基准重排本章时间：开春离家→中途打工数月→秋到鹤川→第四天进店→霍燃腊月里找来。第三章"写了半个月"、第九章"扣了我三个月"随之校准。
