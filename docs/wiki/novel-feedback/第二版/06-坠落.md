# 第六章 坠落 · 点评

## 优点
- 九年前线落地有力：塑料盘子的家庭暴力、"我一点都没有舍不得家"、"我什么都没看见"→"从头到尾，没有人问过我'那天晚上，你在哪儿'"——人物的罪感核心从"没看见"变成"没说"，比第一版实得多。
- 草字头教学（"写错了，就是另一个字了"）为第八章错字摊牌备好燃料；报纸"叶某某"、"那道缝，大人进去都费劲"是好细节。

## 问题
1. **叶蓁之死因果链缺失 + 九天搜寻不搜塔（A 级，全书最大的洞）**：她约他上塔，自己却卡进钟与墙的缝里，把钟卡停——她为何、如何卡进那道缝，全书无一句交代；全城搜寻九天，第九天"修塔的人"才在塔里找到她——塔是第一现场，锁着门但管修缮者与店里都有钥匙，警方九天不进塔搜，程序上说不通。"那道缝大人进去都费劲"只解释了"藏得住"，解释不了"九天不搜塔"。必须补：搜过几轮、缝隙如何被钟体遮蔽、或塔内某段当时无法进入。
2. **"第二天，榛榛来了"时间指示词悬空**：上一段还停在九年前"我就这样回了望江"，"第二天"没有任何着落。应改为"重写完这一章的第二天"或干脆"她来得比我预想的快"。
3. **九月十七 vs 北大开学（A 级）**：市高考状元九月十七仍滞留鹤川、"她过完这个月就去北京"，与高校九月初开学冲突；且大纲人物表写叶蓁"美院没考上，准备去省城复读或打工"，与正文"考上北大"直接互斥。两处设定必须统一。
4. 第六章梦段"我伸出了手"与第十一章话术谱系呼应正确，但"先说我在梦里排练过一千遍的那一段"里的门与光（"到处是门，有几扇门我从来没有见过"）暗示过度，接近第一版的玄虚腔，建议削两笔。

## 修改建议
- 本章是修改优先级最高的一章：先补叶蓁进入夹层的物理过程，再补九天搜寻的合理性，第三统一升学设定。
