# 《现在是几点》创作大纲（第二版 · 依反馈重写）

> 依据：`docs/wiki/策划文档`（游戏概述 / 主角 / 玩家 / 她（榛榛））+ `docs/wiki/novel-feedback/01.md`。
> 风格参考：《永无岛》（水格）——但对话部分从"文学腔"改为"现实动机"驱动（见下）。
> 正文：本目录 `01`—`12` 号文件。

## 〇、创作准则（本版最高优先级）

1. **民警测试**：每个场景，把所有雾气和隐喻剥掉后，人物的行为必须经得起派出所民警的推敲——谁在干什么、为什么、说不说得通。
2. **对话即行动**：每一句台词，人物都在为达成某个现实目的说话（要东西、挡问题、探消息、赶时间、留人）。说不出目的的话，删。
3. **具体压过抽象**：质感由手艺的物理细节承担——零件、油污、价格、工期、天气、身体动作。**禁止哲理性反问、格言腔、"你觉得呢"式的打机锋（除非它正被对方当场戳穿）**。
4. **年龄与身份对齐**：沈叙二十三岁，刚来投奔师傅的学徒——手上有活、嘴笨一半、防御性强；不许说六十岁老江湖的台词。榛榛十九岁——戒备、直接、说话有调查者的目的性。
5. **潜台词藏在不经意处**：双重含义从处境里长出来，不从修辞里长出来。

## 一、一句话故事

鹤川有一口停在十点三十七分的钟。修表的青年遇见一个女孩：她带来一只停走的表、一个被写错的名字、一个死去的姐姐。他以为自己在重新爱一次，其实是在把同一件事再做一遍。
——"现在是几点"，最后落回读者自己头上。

## 三、人物（含"他要什么"）

**沈叙**（23岁）——永明钟表店学徒，从望江来，师傅老顾叫他来帮手（老顾眼睛不行了）。手上活稳，嘴上话不多；不想被人问底细。**要什么**：把自己安顿好，把活做好；越往后，是留住一个人。
**声音**：短句、答非所问、把主动说成被动（"她自己来的""表停的那天"）；不机灵，不油。

**许榛榛**（19岁）——高中毕业，来鹤川打工（照相馆暗房）。姐姐九年前死于钟楼，家里人二十年不提。**要什么**：弄清姐姐死前见的那个人是谁；看一眼就走——后来走不掉了。
**声音**：直接、少字、有问题就问；不设喻。

**叶蓁**（死时17岁）——榛榛的姐姐，学画画，那年美院没考上，准备去省城复读或打工。会跟塔下的少年说话。**要什么**：离开鹤川；被当大人看待。
**声音**：活泼、跳脱、说具体的事。

**老顾**——钟表店老板，修了四十年表。**要什么**：把手艺传下去，把店留住。
**声音**：说活计，不说哲理。

**霍燃**——榛榛老家的旧识，在鹤川打工。**要什么**：把榛榛带回去。
**声音**：短、冲。

**方念（我母亲）**——鹤川人，二十岁那年丧妹、失恋，后远嫁望江。**要什么**：不再回鹤川、不再提旧事。
**文辉**——1990 年鹤川的电影放映员。**阿苹**——阿念的妹妹，14 岁，落水失踪。

## 五、分章场景设计（重写版）

**凡例**：每章按"场景 → 人物要什么 → 障碍 → 结果"设计；对话全部由此生成。

### 第一章 十点三十七分
- 场景一：雾天，钟表店。沈叙的现实处境由老顾一句话交代（"我眼睛不行了，你来帮我干一冬天，管吃住"）。满墙的钟，收活，价目。
- 场景二：榛榛进店**修表**（不是问时间）。对话只围绕：什么表、怎么坏的、能不能修、多少钱、多久。她说钱不多→他看出来→老顾的规矩（修不好不收钱）。收表登记：钟面十点三十七分（他登记收表时间，随口念出；她听见，顿了一下——他在意了）。开盖检查：表壳内侧刻字磨花（他不问）。
- 场景三：她报名字时的迟疑与掩饰（袖口的雨水落在本子上，她拿袖子去擦）。
- 场景四：夜里，塔、钟声（没有响）。框架句。
- 保底功能：10:37（表停、登记时间、她的反应）；磨字；名字；塔的禁忌种子。

### 第二章 裂痕
- 场景一：她隔几天来一次，问进度（真进度：缺零件，等铺子里的旧货）。她坐下等——现实理由（外面冷、下班早、等新闻）。沈叙给她热水、给她看修表的门道（洗油、点油）。
- 场景二：她的打听（朝"以前"去）：这店开多少年、师傅收过几个徒弟、塔上以前有没有出过事。沈叙的回避与警觉。
- 场景三：霍燃首次出现（公交站，他要拖她走/要她回去；她甩开）。
- 场景四：河堤、面摊（香菜细节）；她提塔，他失态："别去那里。"──"为什么？"
- 保底功能：霍燃；"别去那里"；叶蓁记忆碎片（塔顶的风）。

### 第三章 纪实与虚构（上）
- 场景一：母亲寄来的旧铁盒（或老顾寄存的盒子）——信、票根、发卡。现实动机：他被这些旧物缠住，又睡不着。
- 场景二：他开始写（写不像；写景没有活人）。
- 场景三：榛榛读稿："写个人吧。"（新台词，平直）
- 场景四：小说内：1990 年，百货大楼钟表柜台、露天电影、修放映机——全部落在具体物件与价格、单位、时间上。
- 保底功能：阿念、文辉、阿苹登场；"我有一个姐姐"。

### 第四章 在鹤川
- 场景一：送货路线（谁家什么钟、什么故障、收多少钱；城市与人的实表）。
- 场景二：文化宫老电影（牵手；她提姐姐——带着目的）。
- 场景三：上塔检修（老顾给钥匙；钟面 10:37；栏杆刻痕）。
- 场景四：暗房（她让他看到翻洗的旧照片——她有意为之；他装作没看懂）。
- 保底功能：钥匙、照片、塔内刻痕。

### 第五章 榛·独自站立
- 全章榛榛第一人称，口语、去抒情：姐姐死后家里怎么过的（妈妈锁房间、不许提、改嫁、改姓）；她从樟木箱里翻出日记（她几岁、怎么翻到的）；她为什么来鹤川（高中毕业、没出路、想弄清姐姐死前见的人）；她怎么找到店里（日记里"钟表店的小孩"）；进店第一天带的**画**（姐姐画的速写）——她在门外看了几天。
- 保底功能：她的动机全部现实化；霍燃有一句台词；"最后一次"的决心。

### 第六章 坠落
- 场景一（现在）：榛榛拿照片来问（重写版：她把照片拍在柜台上，让他念背面的字——他念不出；她收起照片："那我按不知道算。"）。
- 场景二（九年前·重写）：那年他 14 岁，寄住在钟表店。叶蓁是塔下画画的姑娘。**那天她来叫他，说她下月要走**（没考上，去省城投奔亲戚/打工）；约他傍晚塔上见（有东西给他）。塔上：程越来收尾（"明天封塔"）；她把一个旧画夹从角落的杂物里取出来（藏在塔上的东西）——**她要给他的是一件实在的东西**（她的速写本或者一支笔——定稿：一张画，画的就是他）。
- 场景三（坠落，物理链）：她看时间（赶末班车/天要黑）→低头看腕上的表（表本来就不走/走不准）→随手把表摘下来递给他看（"你看看，还能不能修"——**她本来就想把表留给他修**）→表带断了，表滚到栏杆外沿的边石上→她伸手去够（或翻出去够）→手/脚一滑→他扑过去拉→拉空。
- 场景四：之后的几天（笔录的现实版本；他为什么说"我什么都没看见"——他说的其实是实话：那一下他没看清，他只记得自己抓了个空，说出来没人信，也没人问得那么细；母亲来接他走）。
- 保底功能：表；"你别过来"（她在栏杆外喊）；"我现在几点"→改为她问"几点了，末班车还有没有"；扣子/指尖；"我什么都没看见"。

### 第七章 纪实与虚构（下）
- 阿苹之死（落水夜，现实链：母亲禁足、阿苹替她传话、雨、河堤）；母亲的重话；文辉的告别（把票根留给阿念）；阿念嫁人（第二年）。
- 现实线：电话（"饼干盒的信，我看了"）；榛榛点破"你在给你妈写传"（重写为举证先行）。
- 保底功能：全部既有情节线；结尾的邀约（"要么你拦我，要么，你跟我走"）。

### 第八章 她的名字
- 钟楼白天摊牌（重写理由链）：她要走了（车站八点零五），走之前把话说完。她的证据链：照片（底片是她从家里带来的）、日记、**那张写错名字的练习纸**。逐件摆出来，逼他回应。
- 他的反应：从"编不出来"到"直接承认细节"（"你姐姐那天把表递给我的时候，手是凉的"提前泄露到位？不——保持第八章为"名字"章：他的崩溃点=那张纸）。
- 保底功能：名字真相（草字头）；"你认出来过吗"；表的归属；"你爱的是谁"。

### 第九章 离
- 隔门对话（重写：她不见他；他的挽留现实化——打电话、在楼下等、堵门；话术被逐条戳穿）；霍燃冲突（打架的现实动机：霍燃来要钱/来带她走）；老顾的活计话；深夜敲门（她的告别稿：送走霍燃、留下表、"陪我去一趟钟楼，说完就走"）。
- 保底功能：看守/证物判词；一巴掌；钥匙将军。

### 第十章 深夜的催眠术
- 元层面章（保留结构，微调语言）。保底功能：机制、虚假选择、"二月十四，凌晨三点一刻"。

### 第十一章 凌晨三点一刻
- 上塔理由（她要走了，最后一次看姐姐死的位置）；争执的现实内容（她摊了底牌：她知道他那天在场/她要去报警吗？──定稿：她说"我不报警。我就是去看一眼，然后走。"他要她留下/要她别说出去）；动作链（抓手腕—甩开—后退—绊在排水口铁盖/平台上的杂物—翻落/滑落——三个版本保留）；"你别过来"；"几点"（她在算车）；"还早"/"不早了"。
- 保底功能：全部呼应句群；"我把手伸出去了"；作证。

### 第十二章 现在是几点
- 收束：笔录的现实版本（这次的证词）、母亲的到来（"跟你爸一样"）、表的去向、岛、最终问答、后记乐句。

## 六、第一版病症对照（重写红线）

| 病症 | 第一版例句 | 处理 |
| --- | --- | --- |
| 伪交锋（复读机） | "很久。""多久？""……很久。" | 删除；改为实在的回答（几年、翻出来的） |
| 打机锋 | "你要它走，还是要它准？" | 删除；改为零件与误差的实谈 |
| 油腻台词 | "表在我这儿。你就得回来。" | 删除；改为老顾的规矩（修不好不收钱） |
| 无动机动作 | 进门先问"现在几点" | 改为修表；10:37 由收表登记带出 |
| 提线木偶 | "对。就是这样写的。"（监督写字） | 改为迟疑+水渍掩护+默记 |
| 哲理性反问 | "你觉得呢"（在无关紧要处） | 只在低风险处出一次，关键场景被当场戳穿 |
| 年龄错位 | 23 岁学徒的江湖腔 | 全部降为干活人的短句 |
