# 《现在是几点》创作大纲（第二版 · 依反馈重写）

> 依据：`docs/wiki/策划文档`（游戏概述 / 主角 / 玩家 / 她（榛榛））+ `docs/wiki/novel-feedback/01.md`。
> 风格参考：《永无岛》（水格）——但对话部分从"文学腔"改为"现实动机"驱动（见下）。
> 正文：本目录 `01`—`12` 号文件。

## 〇、创作准则（本版最高优先级）

1. **民警测试**：每个场景，把所有雾气和隐喻剥掉后，人物的行为必须经得起派出所民警的推敲——谁在干什么、为什么、说不说得通。
2. **对话即行动**：每一句台词，人物都在为达成某个现实目的说话（要东西、挡问题、探消息、赶时间、留人）。说不出目的的话，删。
3. **具体压过抽象**：质感由手艺的物理细节承担——零件、油污、价格、工期、天气、身体动作。**禁止哲理性反问、格言腔、"你觉得呢"式的打机锋（除非它正被对方当场戳穿）**。
4. **年龄与身份对齐**：沈叙二十三岁，刚来投奔师傅的学徒——手上有活、嘴笨一半、防御性强；不许说六十岁老江湖的台词。榛榛十九岁——戒备、直接、说话有调查者的目的性。
5. **潜台词藏在不经意处**：双重含义从处境里长出来，不从修辞里长出来。

## 一、一句话故事

鹤川有一口停摆的钟。全城都知道它停在十点三十七分，全城都不提这个数字——那年，市里的状元、塔下画画的姑娘叶蓁，失踪九天后被发现卡死在钟塔里、钟和墙的那道缝里；钟是从那一刻停的，机械里沾过血，从此没人愿意修。九年后，一个不知情的外地修表匠来到鹤川，一个女孩带着姐姐的遗表来找他修——她不是来修表的，她是来问一句话的：那天晚上，你到底在不在塔上。

## 二、与策划文档的对应（修订）

| 策划文档的设定 | 小说中的实现 |
| --- | --- |
| 玩家（催眠师）代入主角，从错乱叙事中寻找真相 | 每章章首斜体短句是"你"的提问；第十二章揭示"你"的三层回声 |
| 早期旁观、美好记忆 → 中期"你就是主角" → 末期超越时间 | 一至四章 → 五至九章 → 十至十二章 |
| 两个结构相似的命案（一次与主角无关，一次由主角实施） | 叶蓁之死（困死于钟塔夹层，无凶手，与"我"无关）与榛榛之死（同一座塔内坠落，"我"实施）：两个女孩都没能走出那座塔 |
| 混淆的指代 | "榛／蓁"同音错字；"她"与"你"在全书滑移 |
| 元层面的她 | 结尾："你"是谁，由读者最后一步决定 |

**10:37 的三重结构**：钟塔停摆的时刻 = 叶蓁被卡住的时刻 = 叶蓁的表停摆的时刻（表的遗物，榛榛带来的那只，停在 10:37）。（表不区分昼夜：谁也不知道那一下是上午还是晚上。）

**两个女孩的位置**：叶蓁死在塔身与钟的夹层里（"困死"）；榛榛死在塔内的检修爬梯下（"坠落"——"我"实施）。两案句群呼应更新为：雨／回头／"你别过来"／抓着爬梯的手，指节发白／我伸出了手／她往下走。

## 三、人物（含"他要什么"）

**沈叙**（23岁）——永明钟表店学徒，从望江来，师傅老顾叫他来帮手（老顾眼睛不行了）。手上活稳，嘴上话不多；不想被人问底细。**要什么**：把自己安顿好，把活做好；越往后，是留住一个人。
**声音**：短句、答非所问、把主动说成被动（"她自己来的""表停的那天"）；不机灵，不油。

**许榛榛**（19岁）——高中毕业，来鹤川打工（照相馆暗房）。姐姐九年前死于钟楼，家里人二十年不提。**要什么**：弄清姐姐死前见的那个人是谁；看一眼就走——后来走不掉了。
**声音**：直接、少字、有问题就问；不设喻。

**叶蓁**（死时17岁）——榛榛的姐姐，学画画，那年美院没考上，准备去省城复读或打工。会跟塔下的少年说话。**要什么**：离开鹤川；被当大人看待。
**声音**：活泼、跳脱、说具体的事。

**老顾**——钟表店老板，修了四十年表。**要什么**：把手艺传下去，把店留住。
**声音**：说活计，不说哲理。

**霍燃**——榛榛老家的旧识，在鹤川打工。**要什么**：把榛榛带回去。
**声音**：短、冲。

**方念（我母亲）**——鹤川人，二十岁那年丧妹、失恋，后远嫁望江。**要什么**：不再回鹤川、不再提旧事。
**文辉**——1990 年鹤川的电影放映员。**阿苹**——阿念的妹妹，14 岁，落水失踪。

## 五、分章场景设计（重写版）

**凡例**：每章按"场景 → 人物要什么 → 障碍 → 结果"设计；对话全部由此生成。

### 第一章 十点三十七分
- 场景一：雾天，钟表店。沈叙的现实处境由老顾一句话交代（"我眼睛不行了，你来帮我干一冬天，管吃住"）。满墙的钟，收活，价目。**塔的全城避讳**：老顾含糊；街坊一句"那塔上的钟，你们也不接？""不接。"——不解释。
- 场景二：榛榛进店**修表**（不是问时间）。对话只围绕：什么表、怎么坏的、能不能修、多少钱、多久。她说钱不多→他看出来→老顾的规矩（修不好不收钱）。收表登记：钟面十点四十一（普通时间）。**她主动点破 10:37**："十点三十七。是它停的那个点儿。"——他（外地人，不知情）只答"我看到了"。开盖检查：后盖内侧刻字磨花（他不问，职业性地记下）。
- 场景三：她报名字时的迟疑与掩饰（袖口的雨水落在本子上，她拿袖子去擦）——她在核对他写字。
- 场景四：夜里，塔、钟。框架句。
- 保底功能：10:37（表停、她的反应、全城讳莫如深）；磨字；名字；塔的禁忌。

### 第二章 裂痕
- 场景一：她隔几天来一次，问进度（真进度：缺零件，等铺子里的旧货）。她坐下等——现实理由（外面冷、下班早、等新闻）。沈叙给她热水、给她看修表的门道（洗油、点油）。
- 场景二：她的打听（朝"以前"去）：这店开多少年、师傅收过几个徒弟、**塔上以前出过事吧**。沈叙的回避与警觉。
- 场景三：霍燃首次出现（公交站，他要拖她走/要她回去；她甩开）。
- 场景四：河堤、面摊（香菜细节）；她提塔，他失态："别去那里。"──"为什么？"
- 保底功能：霍燃；"别去那里"；叶蓁记忆碎片（塔里的黑暗）。

### 第三章 纪实与虚构（上）
- 场景一：母亲寄来的旧铁盒（老顾交付）——信、票根、发卡。
- 场景二：他开始写（写不像；写景没有活人）。
- 场景三：榛榛读稿："写个人吧。"
- 场景四：小说内：1990 年，百货大楼钟表柜台、露天电影、修放映机——落在具体物件与价格、单位、时间上。
- 保底功能：阿念、文辉、阿苹登场；"我有一个姐姐"。

### 第四章 在鹤川
- 场景一：送货路线（谁家什么钟、什么故障、收多少钱；城市与人的实表）。
- 场景二：文化宫老电影（牵手；她提姐姐——带着目的）。
- 场景三：上塔检修：**这次检修是没人愿意接的活**（文化馆请老顾，老顾推了两年，今年派"我"上——"你上去看看就行，别动里头的东西"）；钟面 10:37；钟架深处（几片叶子、一点擦不掉的深色印子——一笔带过）；老顾讳莫如深。钥匙交接。
- 场景四：暗房（她让他看到翻洗的旧照片——她有意为之；他装作没看懂）。
- 保底功能：钥匙、照片、塔内刻痕。

### 第五章 榛·独自站立
- 全章榛榛第一人称，口语、去抒情：姐姐死后家里怎么过的；日记怎么翻出来的；**姐姐之死的全貌（她知道的版本）**：市里多年的状元、考上北大、通知书到了、人失踪了；全城找了九天；第九天，修塔的人在塔里找到了她——卡在钟和墙的那道缝里，卡了几天，人早就没了；"她卡进去的时候，把钟卡停了。塔上的钟，从那天起停在十点三十七。全城从那天起，不提这个数。"
- 她为什么来鹤川：想知道姐姐为什么进塔／日记里"钟表店那个小孩"是谁。
- 保底功能：她的动机全部现实化；表哥一样的表；霍燃有一句台词；"最后一次"的决心。

### 第六章 坠落
- 场景一（现在）：榛榛拿照片来问（她把照片拍在柜台上，让他念背面的字——他念不出；她收起照片："那我按不知道算。"）。
- 场景二（九年前·重写）：那年他 14 岁，寄住在钟表店。叶蓁是塔下画画的姑娘，也是全城的状元。**她给过他一把塔门钥匙**（她上塔画画，他上塔看书——两个人偷偷的据点）。失踪夜：日记最后一条"今天他要在塔上等我。他说他会写我的名字给我看。"——**他没等到她**：他上塔，等到十点前后，塔里有过一声闷响，他当成风；他没等到人，走了。
- 场景三（真相）：几天后她"失踪"；第九天，检修的人在塔里找到她。他撒谎（没说自己上过塔、有钥匙、等过她）。母亲连夜来接他走。
- 场景四（现在）：照片质问的收尾——"她不是来修表的。"
- 保底功能：钥匙（14 岁一次、现在一次）；"我什么都没看见"；"那一声响"。两个女孩的位置：一个困死、一个坠死。

### 第七章 纪实与虚构（下）
- 阿苹之死（落水夜，现实链：母亲禁足、阿苹替她传话、雨、河堤）；母亲的重话；文辉的告别（把票根留给阿念）；阿念嫁人（第二年）。
- 现实线：电话（"饼干盒的信，我看了"）；榛榛点破"你在给你妈写传"（重写为举证先行）。
- 保底功能：全部既有情节线；结尾的邀约（"要么你拦我，要么，你跟我走"）。

### 第八章 她的名字
- 钟楼白天摊牌（理由链）：她要走了（车站八点零五），走之前把话说完。证据链：照片（底片是她从家里带来的，背面日期=失踪日）、日记（最后一条："今天他要在塔上等我。"）、写错名字的练习纸。**她的核心逼问："那天晚上，你在塔上吗？"**——他一层层退，退到名字上（错字真相："你到死都写不对她的名字"）。
- 保底功能：名字真相（草字头）；刻字"等我"；表的归属；"你爱的是谁"。

### 第九章 离
- 隔门对话（她不见他；他的挽留现实化——打电话、在楼下等、堵门；话术被逐条戳穿）；霍燃冲突；老顾的活计话；深夜敲门（她的告别稿：送走霍燃、留下表、"陪我去一趟钟楼，说完就走"）。
- 保底功能：看守/证物判词；一巴掌；钥匙将军。

### 第十章 深夜的催眠术
- 元层面章。保底功能：机制、虚假选择、"二月十四，凌晨三点一刻"。

### 第十一章 凌晨三点一刻
- 上塔理由：她要走了；她要**下去看姐姐被卡住的那道缝**（她拿到了检修口的路径：从平台边缘的铁爬梯下到钟室/夹层）。他拦不住/不许；争执在检修口；她下爬梯——"你别过来"——她往下走——坠落（三个版本保留）。
- 句群（与叶蓁案全呼应）：雨／回头／"你别过来"／抓着爬梯的手，指节发白／我伸出了手。
- 保底功能："还早"/"不早了"；"我把手伸出去了"；作证。

### 第十二章 现在是几点
- 笔录的现实版本（这次的证词；"她下去干什么"——"她要去看她姐姐出事的地方"）；母亲的到来（"跟你爸一样"）；表的去向（第二次停摆，10:37）；岛；最终问答；后记乐句。
- 保底功能：两个女孩的位置在最后对齐（"她们谁都没有走出那座塔"）。

## 七、第三版关键改动（相对第二版）

- **叶蓁之死**：由"雨夜坠楼（主角在场目睹）"改为"失踪九天后被发现卡死在钟塔夹层"——无凶手、全城讳莫如深。
- **10:37**：由来历不明的"巧合"改为事件核心——钟停 = 她的死亡时刻 = 表的停摆；全城绕开这个数说话。
- **主角的位置**：由"目睹坠楼的旁观者"改为"当晚在塔上等过她、有钥匙、没敢说出口的人"——他的谎言从"没看见"变成"没说"，罪感更实。
- **榛榛之死**：由"平台栏杆坠落"改为"塔内检修爬梯坠落"——两个女孩死在同一个"里面"（她要下去看姐姐卡住的那道缝）。
- **老顾**：新增层次——当年被请去修钟、拒修；如今派不知情的徒弟上塔。
- **两案句群呼应**（更新）：雨／回头／"你别过来"／抓着爬梯的手，指节发白／我伸出了手／她往下走。
