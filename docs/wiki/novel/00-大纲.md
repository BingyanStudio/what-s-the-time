# 《现在是几点》创作大纲

> 依据：`docs/wiki/策划文档`（游戏概述 / 主角 / 玩家 / 她（榛榛））。
> 文本风格与叙事结构模仿水格的长篇小说《永无岛》（原名《隔着栅栏的爱情》，中国少年儿童出版社，2009）。
> 小说正文：本目录下 `01`—`12` 号文件，共十二章。

## 〇、一句话梗概

鹤川有一口停在十点三十七分的钟。修表的青年遇见一个女孩，她带来一只停摆的旧表、一个被写错的名字和一个死去的姐姐。他以为自己在重新爱一次，其实他在重新杀一次。
——"现在是几点"，是一个没有答案的问题。

## 一、作品定位（与策划文档的对应）

| 策划文档的设定 | 小说中的实现 |
| --- | --- |
| 玩家（催眠师）代入主角，从错乱叙事中寻找真相 | 全书由第二人称"你"的短句切分为十二个"被唤回的时刻"，与主人公的叙述相互拉扯 |
| 早期：旁观者视角，被误导的美好记忆 | 一至四章：雾、旧表、河堤、露天电影，温柔而缓慢 |
| 中期：逐渐被放在"你就是主角"的位置 | 第五章"我"字易主（视角切换）；此后叙述的破绽逐一显形 |
| 末期：超越时间的存在；"现在是几点"失去意义 | 第十至十二章：深夜的催眠术、"凌晨三点一刻"的重演、一座没有时间的岛 |
| 两个结构相似的命案（一次与主角无关，一次由主角实施） | 叶蓁之死（悬案，与"我"无关）与榛榛之死（"我"实施）：同一座钟楼、同一句遗言、同一组句子 |
| 混淆的指代 | "榛"与"蓁"同音异字；"她"与"你"在全书滑移，最终滑向读者 |
| 元层面的她（《谁是劳拉》式） | 结尾揭示："你"有三层回声，她住在最里面一层 |

## 二、风格与结构设计（对《永无岛》的模仿）

**文本风格（学水格）**

- 第一人称、回望式叙述；抒情与白描彼此侵入，感伤而克制。
- 短句成段与长句段落交替；破折号引出插入语与结论（"——这就是鹤川。"）。
- 比喻冷而身体化；景物带情绪（雾、雨、雪、烟、河、钟声）。
- 人物名字有寓意；地名具体到街巷，让城市成为角色。
- 对话朴素，直接引语与转述混用；心理独白坦率到近乎自伤。

**叙事结构（学《永无岛》）**

- 章回体标题：意象短语命名章节（"裂痕""坠落""离"）。
- 多人物第一人称视角切换：主线为"我"（沈叙），第五章整章换成"她"（榛榛）自述。
- 嵌套叙事："我"在写一部没有名字的小说，讲上一代人（阿念）的爱情——"纪实与虚构"两章。
- 时间线跳跃：现在、九年前、一九九〇年三层时间交错剪辑。
- 死亡与告别收束：两起坠落、一场奔丧式的离城，最后与成人的世界和解不成、只是离开。
- 结尾附一段极短的后记式乐句。

**本书独有的装置**

- 每个时刻都是一次"被唤回"的记忆：章首斜体短句是"你"的提问，为结局的元层面翻转埋线。
- 时间点即章节名：十点三十七分、凌晨三点一刻——它们是钟表停摆的时刻，也是两起命案的时刻。
- "榛／蓁"同音异字构成全书最大的指代诡计；"她"与"你"两个代词持续滑移。

## 三、人物表

**沈叙**（"我"，二十三岁）——鹤川永明钟表店的修表匠。从望江来，说不清为什么回来。擅长说话，擅长把每件事说成另一件事的样子；十四岁那年在鹤川住过一年。

**许榛榛**（十九岁）——在鹤川照相馆做事。冷淡，锋利，口袋里装着一只停摆的旧表。姐姐叶蓁死于九年前的钟楼。

**叶蓁**（死时十七岁）——榛榛同母异父的姐姐。会画画，喜欢坐在钟楼栏杆外侧看云。死于十点三十七分。她的名字里有一个草字头。

**"你"**——一直在提问的人。是催眠师，是她，也可能，是你。

**顾永明**——永明钟表店的老人，修了一辈子表。收留我，也看着我，像看一只走时不准的钟。

**宋戈**——榛榛的同学，纯良，话多，把每个人都往好处想。

**霍燃**——榛榛青梅竹马的人，脾气坏，摔东西。榛榛说：至少他摔东西的时候，我看得见碎片。

**方念（阿念）**——我母亲。年轻时在鹤川，有过一段没有结尾的爱情，和一个落水失踪的妹妹阿苹。她从不提鹤川。

**文辉**——一九九〇年鹤川的电影放映员，会修机器，会在幕布后面抽烟。阿念小说里的那个人。

**程越**——九年前钟楼修缮的施工员，与叶蓁有过争执，被调查过，没有定罪，离开了鹤川。

## 四、三层叙事与时间线

| 层 | 时间 | 内容 | 载体 |
| --- | --- | --- | --- |
| 现在线 | 二〇一五年前后，秋 | 沈叙回到鹤川，遇见榛榛；恋爱、裂缝、两起案件的真相、坠落 | 第一、二、四、五、八、九、十一、十二章 |
| 九年前线 | 沈叙十四岁那年夏秋 | 少年沈叙与叶蓁；钟楼上的坠落；"我什么都没看见" | 第二、四章碎片，第六章全貌 |
| 小说内线（"纪实与虚构"） | 一九九〇年 | 阿念与放映员文辉；妹妹阿苹落水失踪；没有结尾的爱情 | 第三、七章 |
| 元层面 | 现在，催眠中 | "你"把"我"唤回鹤川；虚假的选择；第 N 次重演 | 各章章首短句；第十、十二章全貌 |

**三次坠落／消失**：一九九〇年阿苹落水（失踪，没有尸体）→ 九年前叶蓁坠楼（悬案）→ 现在榛榛坠楼（"我"实施）。
历史在同一个城市里，用同一种姿势向下坠落。

**关键物件**：停摆的旧女表（表壳内侧刻着一个模糊的字，停在十点三十七分）；钟楼主钟（停摆多年）；榛榛送到店里的表、照片、姐姐的日记。

**关键句子（两案的逐句呼应）**：雨从她的头发上滑下去／她回头看了我一眼／"你别过来。"／她的手在栏杆上，指节发白／我伸出了手。／"她从那里掉下去了。"

**四次回声**："现在，是几点"——第一章（榛榛进店）、第六章（叶蓁在塔上）、第十一章（榛榛在塔上）、第十二章（读者）。
**两句终语**："还早。"（他说）／"不早了。"（她答）——第十一章。
**话术谱系**："你觉得呢"（第一、二、四、八、九章逐步显形，第九章被"我不替你答"顶回）；"她从那里掉下去了"（第六章警察前）→"这一次，我把手伸出去了"（第十一章作证）→"我把她送下去了"的未言之语（全书不写出，留在水面下）。

## 五、十二章细纲

### 第一章 十点三十七分
- 视角：沈叙（现在线）。章首斜体：*你问我，现在是几点。*
- 我自我介绍（名字的解释：叙述的叙），鹤川的雾，钟表店，老顾，满屋子的钟。
- 十点三十七分，榛榛推门进来，先问了一句"现在几点"，然后从口袋里拿出一只停摆的旧女表要修。
- 我拆表：表壳内侧刻着一个字，笔画磨得极浅，认不真切。
- 收尾：表留在柜台上；我没问她的名字。她也没问我的。

### 第二章 裂痕
- 章首：*你问我，为什么。*
- 修表往来变成见面：河堤、旧书店、公交站。她像猫一样警惕；我用练过的温柔靠近她。
- 第一次撞见霍燃：公交站，一个男孩叫她，她脸色变了。
- 插叙少年碎片（不注明时间）：塔顶的风，一个姐姐的声音"别上来"。
- 她说想去看看钟楼。我说"别去那里"。她长久地看我："为什么？"

### 第三章 纪实与虚构（上）
- 章首：*你说，从头写。写一个女人的故事。*
- 我开始写一部没有名字的小说：在钟表店抽屉里找到旧信与铁盒。榛榛在阁楼看雨。
- 小说内容：一九九〇年，鹤川。阿念与电影放映员文辉的初遇（大雨、渡口、白幕布、自行车）。
- 现实：榛榛读我的手稿，问"这个女人后来怎么样了"；我说"我还不知道"。
- 收尾：榛榛说："我有一个姐姐。"

### 第四章 在鹤川
- 章首：*你问我，你认出她了吗。*
- 我为老顾送货修表，借路线铺开鹤川：钟楼巷、白鹭桥、鹤川二中、照相馆、旧戏院。
- 与榛榛看一场老电影（黑暗中我第一次牵她的手，她的手很凉）。
- 老顾受托带我第一次上钟楼检修旧钟（钥匙伏笔）。钟面上的时间仍是十点三十七分。
- 暗房：我看见她洗的一张旧照片——钟楼，栏杆边一个女孩。我没问。我什么都没问。
- 收尾：照片背面的日期，我认得。

### 第五章 榛·独自站立
- 章首：*你说，现在，换她说话。*
- 全章切为榛榛的第一人称：她的家庭（母亲、改嫁、姐姐之死后的崩坏）；她"硬"的原因。
- 她来鹤川的原因：姐姐日记里的"沈叙"。进钟表店那天，她先问了一句废话"现在几点"。
- 她对沈叙的矛盾：她本想看清楚这个人，却在修表的安静里第一次松下来。
- 霍燃：她离不开的旧生活。她写："这是我最后一次。不管答案是什么。"
- 收尾：她在钟楼栏杆上摸到一处很旧的刻痕，把手指放了上去。

### 第六章 坠落
- 章首：*你问我：那一天，是几点。*
- 本章前半部故意模糊时间：雨、栏杆、回头、"你别过来"——读者以为是榛榛，直到时间状语揭破：这是九年前。
- 叶蓁之死全貌：十四岁的我；叶蓁把表塞给我"帮我拿着，它走得不准了"；她问"现在是几点"；她翻到栏杆外侧；我伸出手；袖口的扣子、只抓到空气。
- 笔录里，十四岁的我说："我什么都没看见。"——选择性陈述的起源。
- 母亲连夜带我离开鹤川。
- 收尾：现在线。榛榛拿着那张照片问我"照片上的女孩是谁"。我说："她从那里掉下去了。"我不知道我说的是谁。

### 第七章 纪实与虚构（下）
- 章首：*你说，把没写完的写完。*
- 小说下半：阿苹落水失踪；流言；阿念与文辉被拆散；文辉离开鹤川；阿念嫁人，离开。
- 现实：我再也写不下去，给母亲打电话；她恼火，"少打听以前的事"。
- 榛榛点破："你写的是你妈。"
- 收尾：榛榛说："明天带我去钟楼吧。你不是说，不要我一个人去吗。"

### 第八章 她的名字
- 章首：*你说，问吧。*
- 钟楼（白天，雨）。榛榛摊牌：叶蓁是她的姐姐；表是姐姐的遗物；日记里有我的名字。
- 核心揭示：我当年把"蓁"写成了"榛"；"榛榛"是姐姐给她的昵称。她问："你认出来过吗？"
- 她起初是来看"杀死姐姐的人长什么样"的；但她的动摇是真的。
- 收尾：她把表放在我手心里。"它停在十点三十七分。她死的那天。现在你告诉我，你爱的是谁。"

### 第九章 离
- 章首：*你问我，你爱的是谁。*
- 摊牌之后：她要走。我的挽留开始变形——电话、堵门、"你觉得我会吗？"式的武器。
- 她说："你不是在爱我。你在看守我。像看守一个证物。"
- 霍燃来找她。我打了他（第一次动手的预演）。她跟他走，没有回头。
- 老顾说："表坏了可以修。人坏了，修不好。"
- 收尾：深夜，她回来敲门。"你陪我去一次钟楼吧。有些话，我要在那里说完。"

### 第十章 深夜的催眠术
- 章首：*你关掉了录音机。*
- 全章为元层面：第二人称"你"的工作记录与深夜问答。冷、短句、对话体。
- 机制文学化：你输入时间；你以为你能救她；每一次"让她活下来"的回放都让结局更紧。
- "我"抗拒："你知道这不是记忆。你知道这是重演。"
- 你的声音偶尔与她的声音重合；你也在问时间。
- 收尾：你写下"第 N 次。凌晨三点一刻。"我说：不要。你按下了开始。

### 第十一章 凌晨三点一刻
- 章首：*你没有问我。*
- 那一夜的全部：钟楼、雨、钥匙、台阶。她想去姐姐坐过的位置告别。
- 她问"现在是几点"；我低头看表；她说"你别过来"；我过去了。
- 与第六章逐句呼应：雨、回头、栏杆、指节、我伸出了手。
- 之后：我站在塔下；停摆的钟没有响；雨下了很多天。
- 收尾：我对某个人说了一句"她从那里掉下去了。"后面跟了一句"我把手伸过去了。"——两个版本，都在。

### 第十二章 现在是几点
- 章首：*你问我：现在，是几点。*
- 案后的收束（模糊处理）：笔录、遗物、被接走；与九年前的重演。
- 元层面最终对谈：你合上本子；钟表店的钟全都不走了——或者全都走起来。
- 揭示："你"的三层回声（催眠师／她／读这本书的人）。"她"的指代最终滑向读者。
- "没有时间的岛"：她坐在白色的栏杆上问他时间；他说这里没有时间；她说那我们永远都在这个时间。你们永远在一起。
- 最后一句：*——现在，是几点？*
- 附录：极短后记《隔着时间的栅栏》（三五行，作者退场式的乐句）。
