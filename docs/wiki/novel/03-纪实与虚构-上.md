# 第三章 纪实与虚构（上）

*你说，从头写。写一个女人的故事。*

十月底，老顾让我上阁楼清东西。他说阁楼堆了几十年的破烂，我晚上睡在下头，万一哪块板子塌了，砸的是他徒弟，不是他。

阁楼上一个下午清出三麻袋：旧报纸、坏闹钟、断了的钟摆、一箱子卖不出去的塑料表。最里头，柜子后头，摸出来一个饼干的铁盒。

"这个，"我拿下来给老顾看，"谁的？"

老顾戴上两副眼镜看了看盒子上那两个外国小孩。

"你妈的。"他说。

"我妈的？"

"那年她放在这儿的。"老顾想了想，"十七年前？不止。她说改天来拿。后来就没来过。"

"这玩意儿还留着？"

"你自己的东西，你自己定。"他说完就下楼了。

我把盒子放在窗台上，放了两天没碰。白天修表，晚上睡觉，它就那在儿。第三天夜里我睡不着，起来把盒子打开了。

里面是信，用根橡皮筋捆着，橡皮筋一碰就断了。信下面压着几张小照片，黑白，边上带白。还有一张电影票根，字全褪了，剩一个"鹤"字。最底下是一只发卡，弯的，塑料的，酱红色。

信一共九封。写信的人我不认识，收信的人我也不认识。信里的字很小，挤得很密，说的都是过日子的东西：这个月奖金十块，你哥的棉鞋买大了，下雨，修鞋的涨价了。

只有一封不一样。很短，一行：

"阿念，我在渡口等你，等到电影散场。"

我看了三遍。看第三遍的时候，我才发现自己把信纸举到离眼睛很近的地方，快碰到鼻子了。

我母亲叫方念。单名一个念。

那两天我睡不着，就拿信出来看。看完信看照片，照片糊得认不出人。我从来没问过我母亲鹤川的事，她也从来不说。她这个人，你要是问她过去，她就把话题拐到晚饭上，拐得又硬又快，像扑一个火苗。

第三夜，我找了支笔，找了半本用了一半的坐标本。

我在第一页写了一行字：这些是从哪儿来的。想了想，划了。

第二页写：方念，二十岁，鹤川。我又写了这个"辉"字。

写不下去。我光知道两个人：一个叫阿念，一个叫辉。一个渡口，九封信，一只发卡。

然后我把他俩，编着写了一下去。编的时候我给自己立了规矩，贴着东西写——信上出现的钱数、班次、街名、天气，能用就用；一样东西的价格，一趟车要坐几站，那年冬天冷不冷，这些编不对，人就立不住，纸一翻就倒。

我写到后半夜，写下这样一段。

一九九〇年的夏天，鹤川热得柏油路发软，自行车骑过去，轮子上的泥要甩半天才下来。

阿念二十岁，在百货大楼一楼卖手表。柜台是玻璃的，一共三节：左边摆上海牌，中间摆宝石花，右边最贵的一节上着锁。手表是紧俏东西，柜台前天天有人趴着看，看半天，问价，问完不买，第二天再来问。她一天要说几十遍"这个要券"。

她不怕人看，怕没人看。没人看，这个月的营业额就完不成。

夏天的一个晚上，河滩上放露天电影。天擦黑，人扛着板凳往河滩走，幕布用绳子拉在两棵树中间。放映机架在人堆后头，电线从老远接过来。

那天放《人生》。放到一半，机器停了，画面一抖，灭了。人堆先"轰"一声，再是骂，是笑。有人喊"退票"，喊完自己先乐了——露天电影没票。

放映机那头蹲着一个人，手电筒咬在嘴里。他不慌，先关了机器，掀开机壳，把里头一盘片子取出来，对着手电看了看，喊了一嗓子：

"片子热过头了，卡住了！凉一凉，十分钟！"

人堆里有人应："那快点儿，别把好戏凉没了！"

他就蹲在那儿，抽烟，等片子凉。十分钟到了，片子装回去，开机。画面亮了，人堆里"噢"了一声。

光从机器里出来，穿过几百个后脑勺，落在幕布上。所有人都在看幕布。只有阿念站在最后面的沙堆上，看的是蹲在机器旁边的那个人。他在擦手，袖子又黑又亮。

第二次见面隔了一个礼拜。百货大楼门厅的大钟不走了，经理满城找人，有人把放映队的文辉领来了。他背着工具袋，仰着头把那口钟看了一遍，看得脖子上的筋都立起来。

"摆里卡了灰。"他说，"几十年攒下来的。"

他搬梯子，开钟壳。里头黑了半边，灰和油混在一起，积了薄薄一层。他拿刷子扫，拿嘴吹，一修修了一个下午。修完，钟摆"咔"地一声开始走，大楼里的人都抬起头，看那口停了半个月的钟。

阿念看的是他的后脖子。汗从上面下来，在灰上冲出一道一道的白印子。

"你脖子。"她说。

"嗯？"

"脏了。"

他拿手背去蹭，蹭得更花。他笑了。他笑的时候是实在的笑，先出声音，后弯眼睛。

后来，碰上放电影的日子，他就骑车绕到百货大楼后门等她下班。她出来得晚，他就在路灯底下站着。她问他等多久了，他说："刚到。"

他鞋边上有一圈土，是站久了来回蹭出来的。

渡口在城南。公路修起来以后，渡船就荒了，剩几级石阶，长着青苔。他们的约会都在那儿。她先到，就坐在石阶上数船；他先到，就蹲着抽烟。河上没灯，星星掉在水里，碎了又聚，聚了又碎。

阿念有个妹妹，小名阿苹。这一段信上没有，是我编的。

——

十一月里，她来得更勤。有一回赶在饭点上，我锁了门，带她去巷口吃面。老板娘问要不要香菜，她说："不要。"就两个字。我记住了。

吃完饭回来，她看见柜台底下的坐标本——我写东西的本子，一直塞在那儿。

"你天天晚上写什么？"

"瞎写。"

"给我看看。"

"没什么好看的。"

"你写了好几天了。"她说，"我每次来，本子的位置都不一样。"

我看了她一会儿，把本子抽出来，递给她。

她就着柜台的台灯，一页一页翻。翻得很慢。我在旁边擦柜台，擦了两遍，擦到第三遍的时候，她看完了，把本子合上。

"你写了半个月，"她说，"一个人都没有。"

我笑了一下。我知道她说得对。我写的是雾，是河，是柜台上的三节玻璃，是票、券、班次——人呢，写不进去，一写就像假的。

"写个人吧。"她说。

"谁？"

"随便谁。"她把本子推还给我，"有人，屋子才立得住。"

我点点头。她把椅子往后一推，说："这个女人，一个人？"

"有个妹妹。"我说，"信里没写。我编的。"

她"嗯"了一声。过了会儿，她说：

"我有一个姐姐。"

她没往下说。我也没问。她把本子往柜台里推了推，起身要走。

"写完了，给我看。"她说。

我说："好。"

她走了以后，我把稿子收起来，忽然开始在乎它写得好不好。
