# 第三章 纪实与虚构（上）

*你说，从头写。写一个女人的故事。*

我开始写一部没有名字的小说。

开始写它，是因为一只铁盒。

铁盒是饼干盒，长方形的，盖子上印着一男一女两个外国小孩，颜色褪成旧照片那种黄。老顾把盒子拿给我的时候，盒子已经在阁楼的床底下放了十几年。

"你妈的东西。"他说，"那年她放在这儿，说改天来拿。改天，改天，一改就是十好几年。"

我母亲姓方，单名一个念。她年轻的时候在鹤川住过，这是我知道的关于她的往事的全部。我十四岁那年在鹤川住过一年，就住在钟表店的阁楼上。后来我走了，母亲也再没有回过鹤川。她连提都不提。

"她不来拿了？"我问。

"你带回去。"老顾说，"或者——你自己看。反正是你们家的事。"

我把盒子抱上楼，放在窗台上。那天夜里我没有打开它。它在窗台上放了两天，我路过就看见那两个外国小孩的笑脸，笑得一本正经。

第三天夜里，我打开了它。

里面是信，用一根橡皮筋捆着。橡皮筋已经失去了弹性，一碰就断，断口上掉了些细小的碎屑，落在桌子上。信下面压着照片，三四张，黑白，边上带着留白，像从别的什么上面剪下来的。还有一张电影票根，字全褪了，只剩一个"鹤"字。最底下是一只发卡，弯的，塑料的，酱红色，是几十年前满街都在戴的那种。

信一共九封。写信的人我一个都不认识，收信的人也是。信里说的是些家常：粮站、病假、车间调班、下雨、妹妹又长个了。

只有一封信不一样。那封很短，只有一行字。

"阿念，我在渡口等你，等到电影散场。"

那一年我母亲二十岁。

一夜之间，我有了一个母亲不认识的世界。信封上的邮戳模糊，可地址是清楚的：鹤川市安平路。寄信人一栏，写着一个"辉"字。

我在阁楼里坐了整整两夜。第一夜我读信，第二夜我什么也没读，我只是坐着，听楼下的钟一只一只走过整点。我不明白自己为什么要哭。后来我想明白了：我母亲这个人，一辈子强势、多疑、把每个靠近她的人都往外推——我一直以为她天生就是这样。原来她也当过阿念。原来她也等在渡口。原来那个推人的人，也是从被人推开始学会的。

第三个夜里，我摊开纸，开始写一部没有名字的小说。

第一稿写得不好。我写鹤川：雾、河、巷子、钟楼、店里几百只钟一起走。写了厚厚一沓，景物一样一样地摆好，像布置一个很大的、很空旷的舞台。可里面没有人。一个字的人都没有。我写来写去，写的都是东西：钟，雾，雨，桥。

写完我读了一遍，觉得冷。我自己都不愿意在里面多待。

那天下雨。榛榛没带伞，来了店里就不走了，坐在高凳上听雨。她听见楼上有响动——老顾在躺椅上打呼噜，我在楼上——就问老顾，能不能上去看看。

老顾朝天花板努了努嘴："问他。"

她上来的时候，我在写东西，手里的笔差点滚到地上。我站起来，又坐下，又站起来，像个被点到名的学生。她也没笑我。她在天窗底下坐下来，就着那一点灰白的天光，把我摊在桌上的纸拿起来，一页一页地看。

雨敲着屋顶，敲得很密。

"你写的？"

"嗯。"

"写的是鹤川。"

"嗯。"

她把纸放下，叠整齐，还给我。

"你写了半个月，"她说，"一个人都没有。"

我笑了一下。我知道她说得对。

"写个人吧。"她说。

天窗上淌着水，光被水搅碎了，落在她脸上，一小块一小块地动。我说好。我那时候还不知道这个女人是谁，从哪里写起。但我知道她已经在纸的另一面站着，等着，只是我还没有走到能看见她的地方。

一九九〇年，鹤川的夏天长得没有边。蝉从七月叫到八月，叫得人头皮发麻，河堤上的柳树垂着叶子，一动不动。傍晚的太阳落下去，热气还从地上往上冒，像大地在喘气。

阿念二十岁，在鹤川百货大楼一楼的钟表柜台站店。

那时候手表是贵重东西。柜台前总有人徘徊，趴在玻璃上把一只表看半个钟头，钱包在胸口捂出了汗，也不一定买。阿念不怕人看，她怕闲着。她在柜台底下藏着一本《大众电影》，翻到封面上的每个人都变得卷了边，抬起头来，就隔着玻璃看大街上的人。谁骑车骑得快，谁的新裙子好看，她心里都有一本账。

她母亲托人给她说过几门亲事。男方在对面马路新华书店的楼上等，隔着窗户往这边看。

"人家在楼上招手呢。"同伴说。

阿念不抬头，拿抹布擦柜台。"我这儿有客人。"

柜台前面，一个人也没有。

她是在看电影的时候第一次看见文辉的。

那年夏天，河滩上隔三差五放露天电影，全鹤川的人都去。天还没黑，小凳子、马扎、砖头就在河滩上排成了行。电影是八点开始，《少林寺》那一类的，孩子们在场子边上翻跟头，把沙子扬得到处都是。

那天放的是《人生》。放到一半，放映机坏了。画面抖了两下，啪地灭了，人群"轰"地一声，比刚才电影里的锣鼓还响。有人喊："退票！"——露天电影没有票，这个人喊错了，自己也不好意思，缩回人堆里去了。

一个人从人群后面挤过来，走到放映机跟前。他不慌不忙，先关了电源，再打开机壳，手电筒咬在嘴里，油乎乎的袖子挽到胳膊肘上。这期间，起哄的声音他像是全没听见。三分钟以后，机器重新转起来了。

人堆里有人喊了一嗓子："这师傅，哪个单位的？"

画面重新亮起。人群"噢"了一声。

光从放映机里出去，穿过满场人的头顶，落到幕布上。幕布上的人在哭在笑，满场的人也哭也笑。所有人都在看幕布。

只有阿念，站在最后面的沙堆上，看的是跟机器站在一起的那个男人。光把他罩着，把他的影子投得很大，一直投到幕布边上去。

后来阿念跟同伴说，她第一次看见文辉，看见的不是人，是一个影子。

第二次见面隔了一个礼拜。

百货大楼门厅里的大挂钟坏了，停在差一刻三点上，下了班的钟表柜台也没有办法，主任满城找人。有人把文辉领来了。他背着帆布工具袋，进门就站住，仰头把那口钟看了很久，看得脖子后面的筋都绷起来。

"你上次修过电影机。"阿念凑过去。

"我修过很多东西。"他低下头看她，"你看的是哪一次？"

"河滩上。"

"那次人多。"他说，"我没看见你。"

"我知道你没看见。"阿念说，"那天你修机子，油蹭到耳朵上，自己都不知道。"

他笑了一下。他笑的时候，眼睛先弯，然后嘴才跟上，像光先到，声音后到。他搬来梯子，把钟壳打开，一修修了一个下午。钟里的零件比表里的粗，比表里的旧，可道理是一样的：有东西卡住了，你就得把它找出来，拿开。他找的时候脖子仰着，手很稳。阿念在底下给他递东西，递错了两次。他没说什么，把错的递回来，也不看她。

钟修好的时候，"咔"的一声，摆锤开始走。大楼里所有的人都抬起头，看那口停了半个月的钟。

阿念看的是他的额头。他的手上有机油，刚才蹭了一下汗，额头上一道黑。

"你脸脏了。"她说。

他用手背去蹭，蹭得更花了。

"没有。"阿念说，"干净得很。"

那天晚上，他们没有约在别处，是约在渡口。

渡口在城南。老桥修起来以后，渡船就荒了，只剩几级石阶，石缝里全是苔。他们把它当成一个谁也不知道的地方。文辉放完电影多半是九点十点，阿念就先到，坐在石阶上等。河面上有星星，水一动，星星就碎成一片，过一会儿又慢慢聚回来。

她等的那些时间，后来我写进小说里，写了很多遍。我发现我写不好。我等人的时候只会看表，一分钟看三次；她不一样。她等的时候不看时间，看水。水是不知道钟点的。

文辉骑车带她的时候，一只手扶把，另一只手护在后座上。他说他是修机器的，知道什么东西松了就会掉，掉在柏油路上，一磕就碎。她就把脸贴在他的后背上，闭着眼睛。骑过河堤，骑过打烊的副食店，骑过睡着了的一排排房子。她说，她那时候以为，鹤川的路是没有尽头的。

阿念有个妹妹，小名阿苹，比她小六岁。

阿苹是个安安静静的孩子，头发细软，走起路来像踩在棉花上。姐姐的事，家里谁都不知道，只有她知道。那些信，是阿苹替姐姐从收发室捎回来的；那些"去同学家写作业"的晚上，是阿苹替姐姐圆的谎。她从不问姐姐去了哪里，只是每天把姐姐的拖鞋摆在门口，让她夜里回来的时候，一伸手就能摸到。

小说写了半个月。我白天修表，夜里上楼写。鹤川的十一月一天比一天冷，我把电暖器搬在桌边，烤得一只手热，一只手凉。

榛榛断断续续地读。她读得慢，读一页要想一会儿，像在纸的背面上找什么字。有几回我抬头，看见她盯着一页发愣，我问她在看什么，她说："没什么。"

"这个女人后来怎么样了？"她问。

"哪样？"

"她等到那个人了吗？"

"我还不知道。"我说，"我写到这里，就把她放在渡口了。"

"那她不是要一直在那儿等？"

"纸上的她，是可以一直等的。"我说，"我可以不往下写。"

榛榛看了我很久。

"你真残忍。"她说。

我不明白她为什么这么说。写小说的人把一个人放在渡口，让她在下雨之前多等一会儿，这有什么残忍。

"你为什么不往下写？"

"我不知道后来发生了什么。"我说，"我编不出我没有见过的东西。"

她笑了一下。那笑容很薄，一瞬就没了。

那天她走的时候，在巷口站了一会儿。风把她的头发吹起来一缕，她抬手把它按下去。

"怎么了？"

"没事。"她说，"你写吧。"

她往前走了两步，又停下来。她说：

"沈叙。"

"嗯？"

"我有一个姐姐。"

她说完就走了，没有回头。巷子两头都是雾，她走了七八步，人就没有了，只剩下脚步在雾里响，一下，又一下，慢慢变轻。

我站在门口，站了很久。

那是我认识她以来，她说的第一句关于她自己的话。
