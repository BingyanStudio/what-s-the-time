# 第四章 在鹤川

*你问我，你认出她了吗。*

修表这行有一个好处：它让你把一座城市走遍。

老顾年纪大了，眼睛不济，出了巷子的活儿都归我。谁家的座钟慢了，谁家的挂钟不敲了，字条就压在柜台上，歪歪扭扭写着地址、毛病、催不催。我背着帆布工具袋，按着这些字条，把鹤川一条街一条街地走。

我差不多是把这座城市走熟之后，才开始喜欢它的。

钟楼巷是我们的巷子。早上有豆腐脑的摊子，摊主认得每一户的碗；剃头铺的镜子对着马路，剪头发的人看着路，路过的人也看着自己。巷子尽头就是钟楼，塔底下有三家卖旧书的，两家卖香烛的——鹤川人拜塔，逢初一十五，塔下的香灰是热的。

白鹭桥在城中间，桥下的河从北到南。秋天水瘦，露出河心的沙洲，沙洲上立着几只鹭——不是鹤，是鹭，老顾说，鹤早就没了，鹭替它站着。桥栏杆是水泥的，冬天摸上去像冰，夏天却烫手。我修过桥头王家的落地钟，修完出来，看见桥上有人卖烤红薯，我给自己买了一个，站在桥中央吃完，把皮扔进河里。皮在水上打了个旋，走了。

安平路那里有邮局，有副食店，还有一排老楼，苏联式样的，墙厚窗小，阳台上全堆着东西。我按信封上的地址去看过，是十七号。老楼还在，门牌是新换的，铁皮做的，蓝底白字。楼下住着的是不认识的人，门口晾着不认识的衣服。

我在十七号下面站过两次。

鹤川二中离钟楼不远，围墙矮，课间有学生翻墙出来买冰棍，冰棍箱子外面盖着棉被。旧戏院在二中对面，早就不放电影了，改卖家具，门口的海报栏还留着，空的，玻璃上贴着半张褪色的年画。照相馆在安平路和纱厂路的路口，橱窗里挂着一家人的全家福，尺寸很大，笑得都很整齐。百货大楼在城中心，一楼现在卖手机，玻璃柜台亮得晃眼——从前那里是钟表柜台。

我每次送活儿路过百货大楼，都会在门口停一下，隔着玻璃往里看一眼。我不知道我在看什么。柜台没有了，柜台后面的人，我从来也没有见过。

这座城里到处是我母亲的年轻时代。我踩着她踩过的石板，过她过过的桥，在她站过柜台的地方往里看——隔着玻璃，隔着三十年，隔着我自己。

可她一句话都不肯跟我说。

十一月底，工人文化宫周末放老电影。海报贴在门口，油印的，字都洇了：星期六晚上七点，《庐山恋》。

"你去过文化宫吗？"榛榛问我。

"没有。"

"那去。"

星期六下了一场小雪，雪没积起来，化了，路上到处是湿的。文化宫的礼堂是五十年代的，木椅子，椅背上还钉着从前的座位号，铜的，一个不缺。人不多，前排几个嗑瓜子的，中间几对，后排零星坐着几个人。银幕是白的，边缘有点黄，像一张被人收藏了很多年的信纸。

灯一灭，放映窗口亮起来。一道灰白的光从我们头顶后面出来，穿过整个礼堂的空气，落到幕布上。光里有很多细小的灰尘在飞，像雪没有落到地上。

我一直忘不了那道光。

电影演到一半，我把手伸过去，覆在她放在膝盖上的手上。

她的手很凉。她没有抽回去。过了一会儿，她的手指动了一下，从我的手掌底下翻上来，扣住了我的手指。

电影里在说什么，我一句也没有听进去。我记得的只有两件事：她的手指先是凉的，后来慢慢地、慢慢地暖了；还有那道光，从我们身后射过来，一直在我们头顶上。

所有的眼睛都朝着光看，朝着幕布看。

只有我们两个人，低着头，看自己交叠在一起的手。

散场的时候，雪又下起来了，很小。她把手插回外套口袋里，走在前面半步的位置。走到照相馆门口，她站住，说：

"我姐姐看这部电影的时候，哭得比我还凶。"

"嗯。"

"她看完电影，回去就去买了一条一样的裙子。"她说，"穿到了坏。"

她走到玻璃门跟前，停了一下。

"你家就你一个？"

"你觉得呢。"我说。

她看了我一眼。玻璃门开了又合，把灯光和她一起关在里面。

我在门外站了一会儿。雪落在肩上，不大，也不用拍。我抬头往钟楼的方向看，黑夜里其实看不见塔，可我知道它在。

那天夜里我又没有睡好。我把阁楼的窗开了一条缝，风灌进来，吹得桌上的稿纸一张一张地响。

我起身去按纸，看见最上面那张上，是我写了一半的句子。

"阿念又一次走到渡口的时候，天已经……"

后面空着。我坐着，把那半句话看了很久，一个字也接不下去。

十二月初，文化馆来了人，说塔顶的旧钟开年要例行检查，怕一冬雨雪把机件锈死，请老顾上去看看。老顾的眼睛现在只认得了表芯，认不了那种大铁家伙。他让我跟着，给他打灯。

上塔的楼梯是旋的，木头的，一边是墙，一边是铁扶手，扶手让几十年的手盘出了油。走到一半有个小窗，风从窗里灌下来，吹得人耳朵疼。老顾在前面走，走得很慢，一步一停，喘气的声音在圆筒似的楼梯里转来转去，像有好几个人在跟着我们上楼。

平台的边缘围着一圈石头栏杆。栏杆里头，是那口钟。

从塔底下看，它只是塔身上的一张脸；站到它跟前，才知道它有多大。钟面比一张八仙桌还大，指针是铁的，从里面看，像两条焊死的胳膊。钟架上有一层灰，灰上落着几粒鸟粪，几片枯叶被风搜进来，卡在齿轮里。

我举着灯，老顾拿小刷子一点一点扫。

"师傅，"我说，"它停在几点？"

"哪看得清。"老顾说。

我从侧面绕过去，把灯举高。指针的影子在钟面里头拖得很长，我看了很久，才把时针和分针对上。

十点三十七分就是十点三十七分——短针压在"10"和"11"之间，长针指在"37"的刻线上，一分不多，一分不少。

"师傅。"我说，"它停在十点三十七分。"

"十点三十七就十点三十七。"老顾说，"你把灯往这边挪挪。"

我没再说话。我举着灯站在那里，手心出了汗。灯把钟面照出来，也把我自己照出来，在那张巨大的脸上，我的影子又小又黑。

我不知道我在害怕什么。一只表停在十点三十七分，一口钟停在十点三十七分，鹤川这么大，一天有二十四小时，任何两个时刻对上，都比这个难得；可真对上了，好像也说不出有什么道理。

那天风大，平台上的风从四面八方来，吹得人站不稳。我扶着栏杆，往下看了一眼。

鹤川在底下摊开着：河是白的，桥是黑的，巷子里的房顶上都有雪，一层一层，像没有写完的字。全城只有一个地方是站着的——就是我这里。我从没有在这个高度看过她生活的这座城。

我扶着栏杆的时候，手指蹭到几道刻痕。有名字，有年月，有的已经长进了石头里。

其中有一处，我的手指停了一下。那里刻过两个字，很浅。我把手挪开了。

我想，下次，等那件事过去，我带她来看一看。

——我不知道我为什么会有一个"等那件事过去"的念头。那件事是什么，我说不出。可"等那件事过去"这五个字，深深地扎在我心里。

下塔的时候，老顾把一串钥匙解下来，分了一把给我。

"塔上的门，历来是店里代管。"他说，"往后你跟材料，钥匙你拿着。锁不好使，走的时候，别把门敞着。"

钥匙是铜的，磨得发亮。我把它放进兜里，兜里沉了一点。

那一阵子，照相馆的老座机漏光，她来找我去修。画幅相机这种东西，说白了也是一只钟：镜头是眼睛，快门是一片会开合的铁，道理跟表壳里的游丝是一路的。我给它换了皮腔，校了快门速度，试拍了几张。

"你进来，帮我看看这张洗出来没有。"她说。

暗房在照相馆最里面，门上一层黑布，进去的时候她走在前面，回头嘱咐我："慢一点，别碰桌上的盘子。"

红光。

整个房间只有一盏红光，离头顶很近，东西的影子都拖着，长的拖到墙上。药水的味道扑面而来，酸的，又有一点甜。三个白瓷盘并排摆着，里面是液体；绳子横在头顶上，夹子一片一片地挂，像一群晾着的黑蝴蝶。

她拿起一张泡在药水里的相纸给我看。

图片是从白纸上浮出来的。先是灰雾，再是影子的轮廓，最后才是人——从一个白色的世界里，慢慢地、慢慢地游上来。

"这是客人的旧底片。"她说，"底片放潮了，我给翻新一下。"

我不懂底片，我只懂机械。我看的是那几张已经挂上绳子的照片。

第一张：钟楼，从下往上拍的，塔尖顶着一小块天。

第二张：从塔上往下拍，河，桥，一排排房顶。

第三张：塔顶的平台。石头栏杆。栏杆边站着一个人，背影，两只手搭在栏杆上，头发被风吹起来一缕。看不见脸。

我盯着第三张看。

"这张也是客人的？"

"嗯。"她一边夹照片一边说，"旧片子。"

"你以前上过塔吗？"她问。

"没有。"我说。

她"哦"了一声，没再说什么。红光里，她的侧影在照片上晃了一下。

她说话的时候没有看我。红光里她的侧脸是红的，眼睛低着，睫毛投下一小片影子。挂照片的手很稳，比我见过的任何两只手都稳。

那张照片的背面朝上，我看见一行铅笔字，很淡：

"〇六年九月十七。"

我把目光移开。我什么都没说。我什么都没问。

从暗房出来，她的脸在日光灯下白了一下，像刚才在红光里的那个人，被留在了那个房间里。

那天夜里，我回阁楼，把钥匙拿出来看了一遍。

铜的，磨得发亮。和从前一根根手指把它摸亮的那些年月，一样亮。

我想起暗房里的那根绳子。照片挂在上面，一排。最里侧那张，她收工的时候，没有摘下来。
