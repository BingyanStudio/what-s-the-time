# 第四章 在鹤川

*你问我，你认出她了吗。*

店里的活分两种：一种在店里等，一种上门。上门的都是大件——座钟、挂钟、立钟，搬不动，得带着工具袋去人家家里修。老顾的腿爬不动楼了，上门的活归我。

我修过桥头王家的落地钟，那钟打点打错，下午三点敲十三下。王大爷一口咬定是钟记错了年份，他听着不对，是钟的问题。我把它调好，走的时候他非塞给我两个苹果。

修过邮局楼上会计室的挂钟：走快，一天快八分钟。我调了，第二天又快了。跑第三趟才发现，那口钟正对着朝南的窗户，晒一天，快一天。我把它挪了半米，好了。

修过粮站的座钟，发条断了，换一根，收十五。修过澡堂子墙上的电钟，不亮，是线头松了，我拧了拧，白干。

靠这些活，我把这座城走熟了。白鹭桥在正中间，桥下的河从北到南；钟楼巷在城西；邮局、副食店、新华书店都在安平路上；鹤川二中在旧戏院对面，围墙矮，课间有学生翻墙出来买冰棍。

安平路十七号，我去过一次。

信封上写的就是这个号。老楼还在，砖是灰的，门牌是新换的。一楼住着一对老两口。我说大爷，从前住这儿的人家，您认得吗，姓方的。他想了想，说这楼里的住户换了七八轮了，他搬来才十五年。他说完问我是谁，我说没事，找人。

百货大楼我也进去过一次。一楼现在卖手机，玻璃柜台亮得晃眼。我在里头站了会儿，看年轻人挑手机。以前钟表柜台的位置，现在摆着一排充电宝。

十二月里，文化宫周末放老电影，一块钱一张票。

"你去过文化宫吗？"她问我。

"没有。"

"那去。"

礼堂是五十年代的老房子，木椅子，椅背上钉着铜的座位号。人不多，前排几个嗑瓜子的，中间几对，后排零星坐着。银幕是白的，边有点黄。

灯一灭，后面的放映窗口亮起来，一道光穿过整个礼堂，落到幕布上。光里全是灰，在飞。

电影演到一半，我把手伸过去，盖在她手背上。

她的手很凉。她没抽回去。过了一会儿，她的手指从下面翻上来，扣住了我的手指。

电影里演的什么，我一句没记住。我记住的是：她的手一开始是凉的，后来慢慢暖了。

散场的时候，雪又下起来，很小。她把两只手插回口袋里，走在前面半步。走到照相馆门口，她站住。

"我姐姐看这部电影的时候，哭得比我还凶。"她说。

"嗯。"

"她看完电影，回去就去买了一条一样的裙子。"她说，"穿到了坏。"

她走到玻璃门跟前，停了一下。

"你家里，就你一个人？"

"你觉得呢。"我说。

她看了我一眼。我没接下去。她推门进去了，把灯光和雪都关在外面。

我在门口站了一会儿。雪落在肩上，不用拍，自己会化。

我往回来的路上走，路过钟楼巷口，抬头往西看。塔在夜里是个黑影子，上边一截看不太清。

我站了一会儿。我每次路过，都会站一会儿。那时候我以为，这只是习惯。

十二月初，文化馆来了人，说塔顶的旧钟开年要例行检查，怕一冬的雨雪把机件锈死，让老顾上去看看。

老顾没接话。他给来人续了水。

"我眼睛不行了。"他说。

"您带个人，打灯也行。"

老顾看了我一眼，看了很久。

"行。"他说，"让我徒弟上。"

"您不上去看看？"

"腿疼。"老顾说。

上塔的楼梯是旋的，木头的，一边是墙，一边是铁扶手。扶手让几十年的手盘出了油，摸上去不凉。走到一半有个小窗，风从窗里灌下来，吹得人耳朵疼。

老顾跟到了塔顶，可他没往钟跟前去。他在楼梯口站着，两只手揣在袖子里。

平台边上围着一圈石头栏杆。栏杆里头，是那口钟。

从塔底下看，它只是塔身上的一张脸。站到跟前才知道它有多大：钟面比一张八仙桌还大，指针是铁的，从里面看，像两条焊死的胳膊。钟架上落着灰，灰上有鸟粪，还有几片叶子被风搜进来，卡在齿轮里。

我一个人干活：一只手举灯，一只手拿刷子扫。

"师傅，"我说，"它停在几点？"

"别管它停几点。"老顾说，"把叶子扒拉干净，就下来。"

我没听。我绕到侧面，把灯举高。指针的影子在钟面里面拖得很长。我看了半天，把时针和分针对上了。

短针压在"10"和"11"之间，长针指着三十七分的刻线。一分不差。

十点三十七。

我在心里把这个数念了一遍。楼梯口那边没有动静。师傅没催我，也没过来。

钟架里头，铁梁上有一块地方，颜色比别处深，擦不掉。我用指甲刮了刮，颜色还在。我多看了一眼。

"扫完没有。"老顾在后头问。他的声音比平时冲。

"快了。"

"快点。"

我没再说话。我举着灯站在那儿，手心出了汗。灯把钟面照出来，也把我照出来，在那张巨大的钟脸上，我的影子又小又黑。

那天风大，平台上的风从四面八方来，吹得人站不稳。我扶着栏杆往下看。

鹤川在底下摊开：河是白的，桥是黑的，房顶上积着薄雪。全城只有一个地方是站着的，就是我这儿。

我扶着栏杆的时候，手指蹭到几道刻痕。有名字，有年月，有的已经长进了石头里。

其中有一处，我的手指停了一下。那里刻过两个字，很浅。我把手挪开了。

我想，等手里这批活干完，带她上来看一次。

下塔的时候，老顾把一串钥匙解下来，分了一把给我。

"塔上的门，历来是店里代管。"他说，"往后你跟材料，钥匙你拿着。锁不好使，走的时候，别把门敞着。"

钥匙是铜的，磨得发亮。我把它放进兜里，兜里沉了一点。

那一阵子，照相馆的老座机漏光，她来找我去修。画幅相机说白了一台小机器：镜头是眼睛，快门是一片会开合的铁。我给它换了皮腔，校了快门速度，试拍了几张。

"你进来，帮我看看这张洗出来没有。"她说。

暗房在照相馆最里面，门上一层黑布。进去的时候她走在前头，回头嘱咐我："慢点，别碰桌上的盘子。"

满屋子红光，影子拖得老长。药水的味道扑面而来，酸的，又有点甜。三个白瓷盘并排摆着，头顶的绳子上夹着一排照片，还没干透，往下滴着水。

她拿起一张泡在药水里的相纸给我看。图片从白纸上浮出来，先是一层灰雾，再是轮廓，最后是人。

"这张也客人的？"

"嗯。"她一边夹照片一边说，"旧片子。"

绳子上还挂着三张。第一张：钟楼，从下往上拍的，塔尖顶着一小块天。第二张：从塔上往下拍的，河，桥，一排排房顶。第三张——塔顶的平台，石头栏杆，栏杆边站着一个人，背影，两只手搭在栏杆上，头发被风吹起来一缕。看不见脸。

"你以前上过塔吗？"她问。

"没有。"我说。

她"哦"了一声，没再说什么。红光里，她的侧影在照片上晃了一下。

她挂照片的手很稳。照片的背面朝上，我看见一行铅笔字，很淡：

"〇六年九月十七。"

我把目光移开。我什么都没说。我什么都没问。

从暗房出来，她的脸在日光灯下白了一下，像刚才在红光里的那个人，被留在了那个房间。

那天夜里，我回阁楼，把钥匙拿出来看了一遍。

铜的，磨得发亮。

我想起暗房里的那根绳子。照片挂在上面，一排。最里侧那张，她收工的时候，没有摘下来。
